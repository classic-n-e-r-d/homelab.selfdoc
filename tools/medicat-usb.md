# Medicat USB: The Perfect Tool
## What is Medicat?
Medicat is a community created piece of software designed to be installed onto a USB drive and used in tandem with Ventoy. The link can be found [here.](https://medicatusb.com/)

When Medicat is setup, it downloads Ventoy onto the assigned USB drive while also installing boot-able diagnostic software.
- Dozens of programs like gparted are installed which saves tons of time manually installing software one by one.
- Ventoy works nearly identical (besides a different folder name) to it's normal install and allows you to manually install whatever ISO files you want.

I currently have Medicat installed on a really cheap looking/feeling 64gb InfinitKloud USB stick. It allows me to test drive many different Linux distributions, while also having boot-able software to diagnose software issues.
